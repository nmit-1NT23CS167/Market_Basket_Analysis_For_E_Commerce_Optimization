# Market_Basket_Analysis_For_E_Commerce_Optimization

In this project, an e-commerce transaction dataset is subjected to Market Basket Analysis 
(MBA) using data mining techniques. Finding correlations between products that are 
frequently bought together is the main objective. Recommendation systems, cross-selling tactics, and product bundling are then optimized using these insights.

As part of the project, data mining tasks will be carried out using Python (Apriori/FP
Growth algorithms) or Weka. To extract useful insights from transactional data, it will apply 
and evaluate current association rule mining techniques rather than creating an entirely new 
algorithm. The project might also investigate the integration of these mining findings into a 
recommendation system for e-commerce.
